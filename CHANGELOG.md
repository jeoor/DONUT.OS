# Changelog

All notable changes to DONUT.OS are documented here.

## v1.0.0

**Mainline frozen release.**

- Real-time 3D donut software renderer with z-buffer and shade buffer
- a1k0n-style perspective checker background
- FLOW and CHECK+FLOW background modes
- RGB+ palette mode
- Dirty rect composition
- Half-resolution background cache
- TopBar, Toast, Help panel
- SYS / RND / SET system panels
- Stopwatch and Timer
- Factory Reset chord
- Preferences V9 for persistent settings
- Theme system
- Glow effect
- Quality toggle
- Motion profiles
- Idle orbit

## v1.1.0-qol

**QoL release with AutoDim and GO-button DeepSleep.**

- AutoDim after idle timeout
- AutoSleep after long idle timeout
- GO / G0 button DeepSleep
- GO / G0 wake from DeepSleep
- Stopwatch / Timer guard prevents AutoSleep from interrupting active watch usage
- Warning cleanup
