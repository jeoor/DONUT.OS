# References & Credits

DONUT.OS is inspired by these projects and resources. It is a Cardputer-specific firmware implementation — not a fork or wrapper of any listed project.

## Donut Mathematics

- [a1k0n donut math](https://www.a1k0n.net/2011/07/20/donut-math.html) — Original donut math explanation
- [a1k0n obfuscated donut](https://www.a1k0n.net/2006/09/15/obfuscated-c-donut.html) — Obfuscated C donut
- [a1k0n enhanced/header-bg](https://www.a1k0n.net/2006/09/20/obfuscated-c-donut-2.html) — Enhanced version with header background
- [a1k0n no-math donut](https://www.a1k0n.net/2021/01/13/optimizing-donut.html) — Optimizing the donut without trig
- [donut.js](https://www.a1k0n.net/js/donut.js) — JavaScript implementation
