# Release Notes

## v1.0.0 — Mainline Frozen Release

**Status:** Frozen — no further changes planned for this branch.

This is the stable mainline release of DONUT.OS without QoL power management features.

### Included

- Real-time 3D donut software renderer
- a1k0n-style perspective checker background
- RGB+ palette mode
- Dirty rect composition
- Half-resolution background cache
- TopBar, Toast, Help panel
- SYS / RND / SET system panels
- Stopwatch and Timer
- Factory Reset chord
- Preferences V9
- Theme system, Glow, Quality toggle
- Motion profiles, Idle orbit

### Not Included

- AutoDim
- AutoSleep
- GO DeepSleep

---

## v1.1.0-qol — QoL Release

**Status:** Recommended for most users.

Adds power management features for daily use.

### New

- AutoDim after idle timeout
- AutoSleep after long idle timeout
- GO / G0 button DeepSleep
- GO / G0 wake from DeepSleep
- Stopwatch / Timer guard prevents AutoSleep interruption

### Fixes

- Warning cleanup
